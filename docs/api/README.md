# API Reference

This directory contains API reference documentation for all MCP tools.

## Structure

- `ga4.md` - GA4 tools reference
- `gtm.md` - GTM tools reference
- `ads.md` - Google Ads tools reference
- `core.md` - Core/utility tools reference

## Tool Documentation Format

Each tool is documented with:
- **Name**: Tool name
- **Description**: What the tool does
- **Parameters**: Input parameters with types
- **Returns**: Return value structure
- **Examples**: Usage examples
- **Errors**: Possible errors and remediation
- **For AI Agents**: Intent, required args, safety checks, canonical examples

## Status

API reference documentation will be generated as tools are implemented.
