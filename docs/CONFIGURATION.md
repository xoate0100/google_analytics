# Configuration Guide

## Environment Variables

See `.env.example` for all required environment variables.

## Configuration Files

The MCP server uses the following configuration files:

### User Configuration

Location: `~/.mcp/google/config.json`

This file contains user-specific configuration including:
- OAuth scopes for each service (GA4, GTM, Ads)
- Rate limiting settings (QPS and burst limits)
- Data layer validation settings

Example structure:
```json
{
  "profiles": {
    "default": {
      "ga4": {
        "scopes": [
          "https://www.googleapis.com/auth/analytics.readonly",
          "https://www.googleapis.com/auth/analytics.edit"
        ],
        "measurement_protocol_secret": "env:GA4_MEASUREMENT_PROTOCOL_SECRET"
      },
      "gtm": {
        "scopes": [
          "https://www.googleapis.com/auth/tagmanager.readonly",
          "https://www.googleapis.com/auth/tagmanager.edit.containers"
        ]
      },
      "ads": {
        "developer_token": "env:GOOGLE_ADS_DEV_TOKEN",
        "login_customer_id": "env:LOGIN_CUSTOMER_ID"
      },
      "limits": {
        "qps": {"ga4": 5, "gtm": 3, "ads": 2},
        "burst": {"ga4": 10, "gtm": 5, "ads": 4}
      },
      "data_layer": {
        "validation_enabled": true,
        "schema_path": "~/.mcp/google/datalayer-schema.json",
        "monitoring_enabled": false
      }
    }
  }
}
```

### Encrypted Credentials

Location: `~/.mcp/google/credentials.enc.json`

This file stores encrypted OAuth refresh tokens. It is automatically created during the authentication flow.

**Security**: This file is encrypted using libsodium and should never be committed to version control.

### Capability Registry

Location: `~/.mcp/google/capabilities.json`

This file is automatically generated and contains:
- Discovered API capabilities
- Available accounts, properties, containers
- Feature flags and API versions

This file is regenerated when you run `capabilities.refresh()`.

## Initial Setup

1. Copy `.env.example` to `.env` and fill in your credentials
2. Run `auth.login()` to authenticate with Google services
3. Run `capabilities.refresh()` to discover available resources
4. The configuration files will be created automatically

## Configuration Profiles

You can create multiple profiles in `config.json` for different environments (dev, staging, production).

Switch profiles using environment variables or MCP tool parameters.
